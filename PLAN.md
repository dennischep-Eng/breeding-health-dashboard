# Herdbook plan

1. ✅ Database schema + migration for animals, breeding, calving, health events
2. ✅ Validated server functions (add/update/delete records, load sample herd)
3. ✅ Herd calculations: repro status, due dates, dry-off, preg-check and withdrawal alerts, KPIs
4. ✅ Slide-out data entry sheet (service, calving, health, animal) with tag lookup, suggestions, "save & add another"
5. ✅ Basic dashboard: KPI cards and action list
6. ⬜ Rich dashboard: charts (calvings actual/expected, services by outcome, health by category), empty state with "Load sample herd" button
7. ⬜ Records page: filterable history with pregnancy-check result buttons, resolve health cases, delete
8. ⬜ Herd page: animal list and per-animal timeline
9. ⬜ Tests
