# Herdbook

Breeding, calving and health records for a dairy herd, with a dashboard of what needs doing today.

**Tech:** TanStack Start (React 19), Tailwind CSS 4, Netlify Database (Postgres) via Drizzle ORM, Zod, deployed on Netlify.

## Run locally

```bash
pnpm install
netlify dev --port 8889
```
